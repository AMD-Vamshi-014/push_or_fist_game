PHISH OR FISH? — Atria Cyber Utsav 2026
=========================================

A self-contained browser game for the Cyber Utsav interactive stall.

FILES
- index.html: complete game. No build tools, packages, database, or API keys required.

RUN LOCALLY
1. Extract the ZIP.
2. Open index.html in a modern browser.

DEPLOY TO A WEB SERVER
Upload index.html to the web root of any static hosting service or web server.
Examples:
- Apache/Nginx: place it in the configured document root (often /var/www/html/).
- GitHub Pages: publish the folder/repository with index.html at the root.
- Netlify/Vercel: deploy the folder as a static site.

GAMEPLAY
- 10 fictional message scenarios, shuffled each game.
- Player classifies each as Safe, Suspicious, or Phishing.
- Correct answer: 10 points; maximum: 100.
- Instant explanations and safety tips.
- End-of-game answer review.
- Responsive layout for phones, tablets, and computers.

NOTES
- This is a client-side educational game. It does not collect or transmit names or scores.
- Scores are not saved to a server or leaderboard.
- All examples are fictional and use reserved example domains.
- Never ask participants to enter real passwords, OTPs, or financial details.
